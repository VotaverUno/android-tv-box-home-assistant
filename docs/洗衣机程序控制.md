# 家电程序控制：洗衣机（海尔 + 美的双筒）+ 洗碗机

> 目标：在 HA 里选程序、改参数、启动/暂停，而不只是开关机。
> 适用：海尔滚筒洗衣机（haier 集成）、美的 D9 复式洗烘一体机（midea_ac_lan 集成）。

---

## 1. 为什么之前"只能开关机"

| 路径 | 能力 |
|---|---|
| 厂商 App | 云 API + **云程序**（"袜子洗 89 分钟/60℃/2 次漂洗/1200 转"是云端参数组合） |
| HA 集成 | 只暴露了部分实体的**子集**：海尔暴露了程序 select，美的 D9 只暴露了开关+传感器 |
| 底层库 | 美的 `midealan` 的 D9 支持 `set_attribute(db_program/dc_program/running_status)`，只是集成没有把它们做成实体 |

本次改造补上了美的 D9 的 **程序选择 + 启动/暂停**，海尔的程序控制本来就有，只是没做 UI。

## 5. 小爱语音怎么接（可选）

巴法云只支持**开关类**设备，所以无法直接把"选程序"暴露给小爱。做法：

1. 在米家/巴法云建一个虚拟开关（例如"袜子洗"）；
2. HA 自动化：开关打开 → 调 `script.d9_washer_program`（program=underwear）+ `script.d9_washer_start`；
3. 小爱说"打开袜子洗"即可触发。

### 7.1 已有实体（无需补丁）

| 实体 | 类型 | 说明 |
|---|---|---|
| `select.YOUR_DISHWASHER_DEVICE_ID_program` | select | 程序预选（27 种：auto_wash/eco_wash/strong_wash/single_dry/wash_dry…） |
| `select.YOUR_DISHWASHER_DEVICE_ID_mode_select` | select | 洗涤模式；**选中即启动**（底层 `set_work_mode`） |
| `button.YOUR_DISHWASHER_DEVICE_ID_start` / `_pause` / `_resume` / `_cancel` / `_start_delayed` | button | 启动/暂停/继续/取消/预约启动 |
| `number.YOUR_DISHWASHER_DEVICE_ID_delay_minutes` | number | 预约分钟数 |

> 三种模式对应：**智能 = `auto_wash`、节能 = `eco_wash`、超强 = `strong_wash`**。

### 7.2 新增脚本（已创建）

| 脚本 | 用法 |
|---|---|
| `script.dishwasher_mode_start` | 传 `mode`（auto_wash/eco_wash/strong_wash），**选中即启动** |
| `script.dishwasher_program` | 只预选程序（不启动） |
| `script.dishwasher_start` / `_pause` / `_resume` / `_cancel` | 启动/暂停/继续/取消 |
| `script.dishwasher_delay` | 传 `minutes`（0=取消预约） |
| `script.dishwasher_start_delayed` | 预约启动 |

### 7.3 烘干时长：当前做不到（协议缺口）

- App 能设"烘干时长"，是因为**云端下发参数**；
- HA 本地协议库 E1 的 `MessageWork` 布局（来自美的 lua）只有：
  `work_status / mode / additional / wash_region / water_level / water_strong_level / delay / door_auto_open`
  —— **没有 dry_set_min 字节**；
- 因此 `dry_set_min` 目前只能**读**（设备回报），不能写；
- 可行替代：选**含烘干的程序**（`wash_dry` 洗烘 / `single_dry` 单烘干 / `single_disinfect`），或自定烘干时长仍在 App 设置。

> 若要支持自定义烘干时长，需要逆向 `MessageWork`（或另一个 set 消息）中该字段的位置，属于实验性改动，风险较高，暂不默认启用。

## 9. 极简方案（推荐日常使用）

> 目标：**只保留一个"开机/关机 + 功能开关"面板，程序固定为默认值**，不再需要选程序。
> 海尔/美的的**功能开关全部保留**（抖散/新风/童锁/自动投放/防过敏/护理/SPA/抗皱/蒸汽/光等离子/语音/自动开门…），只清理"程序选择"类实体。

### 9.1 一键脚本

| 脚本 | 作用 |
|---|---|
| `script.haier_smart_wash` | 海尔：程序设为 **智慧洗** 并启动 |
| `script.dishwasher_standard` | 洗碗机：预选 **Standard**（不启动） |
| `script.dishwasher_standard_start` | 洗碗机：**一键 Standard 启动** |
| `script.d9_wash_underwear` | 小洗衣机：云程序 **156（内裤）** → 启动（作用于当前选中筒） |
| `script.d9_wash_socks` | 小洗衣机：云程序 **148（袜子）** → 启动（作用于当前选中筒） |

### 9.2 已清理/隐藏的内容

- 删除旧版遗留的不可用实体（`sensor.*_db_program`、`sensor.*_dc_program`，即界面上"集成不再提供此实体"的提示）；
- 禁用海尔多余的程序选择类 select（程序存储位置、云程序来源、空气洗温度、烘干程序/方式、脏污度、特渍、统一衣物材质、运行状态_sel）；
- 保留：海尔 `洗涤程序`/`运行状态` 两个 select（供一键智慧洗脚本使用）。

> 所有禁用都可通过「设置 → 设备与服务 → 实体」重新启用，不会丢失。

### 9.3 使用注意

- 一键启动脚本会**真的启动机器**：确认衣物/餐具已放好、水/电正常再点；
- 海尔机器正在运行时切换程序可能被云端拒绝，建议先关/暂停；
- 洗碗机烧菜程序（Standard）会按设备默认参数运行。

## 10. 美的 D9 云程序与筒位（最终结论，实测通过）

### 云程序 ID

| App 程序 | 云程序 ID | 参数指纹 |
|---|---|---|
| 内裤（左筒） | **156** | 漂洗 3 次 / 基础 40 分 |
| 袜子（右筒） | **148** | 漂洗 2 次 / 基础 28 分 |

### 关键：筒位必须和程序/烘干/启动**组合在同一条 TLV 里**

D9 是 TLV 协议：`<桶> <类型><长度><值>...`。实测：

| 命令 | 结果 |
|---|---|
| `db 04 01 9c`（只写程序 156） | ❌ 程序落到默认筒（右边），筒位不可控 |
| `db 32 01 01`（只写筒位=1） | 只切换"当前选中筒"，后续命令仍可能覆盖 |
| **`db 32 01 01 04 01 9c`**（筒位=1 + 程序=156） | ✅ 设备确认 `location=1, program=156` |
| **`db 32 01 01 06 01 01`**（筒位=1 + 烘干=开） | ✅ 剩余 40 → 201 分（+161 烘干） |
| **`db 32 01 01 02 01 01`**（筒位=1 + 启动） | ✅ 启动左筒 |

所以脚本 `d9_wash_underwear` / `d9_wash_socks` 的写法是：

```
开机 → db32010104019c（筒位1+内裤） → db320101060101（筒位1+烘干） → db320101020101（筒位1+启动）
袜子：把 01 换成 02、9c(156) 换成 94(148)
```

> 记录类型：`0x04`=程序、`0x06`=烘干、`0x02`=启动、`0x32`=筒位（1/2）。
> 本结论已实机验证通过（小爱语音"打开内裤洗"正确启动左筒内裤+烘干）。
